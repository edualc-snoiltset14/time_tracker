# Time Tracker — Landing Page

A simple React landing page for the Time Tracker app, built with
[Vite](https://vite.dev/) and React 18.

## Getting started

```sh
cd landing
npm install
npm run dev      # start the dev server (http://localhost:5173)
```

## Build for production

```sh
npm run build    # outputs static files to dist/
npm run preview  # locally preview the production build
```

## Structure

- `index.html` — HTML entry point
- `src/main.jsx` — React entry / mount point
- `src/App.jsx` — page sections (Nav, Hero, Features, Platforms, CTA, Footer)
- `src/index.css` — all styling (responsive, no CSS framework)
